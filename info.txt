GIT
1. Скачать репозиторий
git clone [link]
2. Заливка в удалённый репозиторий
- add
- commit
- push
3. Команда гиту начать отслеживать изменения в текущей директории
git init
4. Статус фалов в гите
git status
5. Начать отслеживать изменения файла
git add filename
git add . (Сразу все файлы)
6. История коммитов
git log
7. Переключение на ветку
git checkout 'name'
git checkout -b 'name' (создать ветку, если ее нет)
8. Обновляет код с удаленного репозитория
git pull
9. Временное хранилище для полезного кода (положить)
git stash
git stash apply (забрать из стэша)
10. Объединение веток
git merge
git rebase
